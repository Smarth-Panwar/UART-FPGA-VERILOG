# UART Implementation on FPGA (Verilog)

## 📌 Overview
This project implements UART (Universal Asynchronous Receiver-Transmitter) protocol on FPGA using Verilog.

## ⚙️ Features
- UART Transmitter and Receiver
- Baud rate generation
- FSM-based design
- Real hardware testing using switches and LEDs

## 🧪 Testing
- Inputs given using FPGA switches
- Output observed on LEDs
- Verified using simulation and hardware testing

## 🛠️ Tools Used
- Verilog HDL
- Xilinx Vivado
- FPGA Board (Zedboard)
